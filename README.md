# Resume and Cover Letter Builder

This project is a React + Node application for generating a one-page resume and tailored cover letter from a job posting and user profile data.

## Structure

- `client/` - React front-end app
- `server/` - Node/Express back-end API

## Getting started

1. Install dependencies in both `client/` and `server/`
2. Run the backend server
3. Run the frontend development server
